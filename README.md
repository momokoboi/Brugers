# 🔥 Flame Theory - Luxury Burger Restaurant Website

A sophisticated, responsive website for Flame Theory, an upscale burger restaurant that redefines the classic burger experience with premium Wagyu beef and elegant dining atmosphere.

## 🌐 Live Website

Visit the live site: [https://lucapohl-angel.github.io/Brugers/](https://lucapohl-angel.github.io/Brugers/)

## ✨ Features

### 🎨 Design & User Experience
- **Elegant, modern design** with warm color palette reflecting the flame theme
- **Fully responsive layout** optimized for desktop, tablet, and mobile devices
- **Smooth navigation** with anchor links and intuitive user flow
- **Interactive carousel** showcasing signature burgers
- **Professional photography gallery** highlighting restaurant ambiance

### 🍔 Content Sections
- **Hero Section** - Captivating tagline and call-to-action
- **Burger Showcase** - Interactive presentation of signature dishes
- **Photo Gallery** - Four distinct views of the restaurant experience
- **Customer Reviews** - Authentic testimonials with star ratings
- **About Us** - Restaurant philosophy and story
- **Reservation System** - Integrated contact form with validation

### 🛠️ Technical Features
- **Form Integration** - Reservation system powered by Formspree
- **Input Validation** - Client-side validation for all form fields
- **Google Maps Integration** - Direct link to restaurant location
- **SEO Optimized** - Semantic HTML structure and meta tags
- **Accessibility** - WCAG compliant design elements

## 🔧 Setup & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lucapohl-angel/Brugers.git
   cd Brugers
   ```

2. **Serve locally:**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx serve docs
   ```

3. **View in browser:**
   Navigate to `http://localhost:8000/docs/`
